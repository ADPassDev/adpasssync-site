Before you begin

The Quick Start Guide, included in every download, lists the full requirements and the network ports between zones. Its checklist for before you install:

  • Verify the installer’s signature: Get-AuthenticodeSignature .\ADPassSync-<version>.msi should show AD Argus Cybersecurity Corporation and status Valid.
  • Create an AD security group for console administrators. The default name is ADPassSync Admins. Add yourself.
  • Create an AD service account for the relay, for example svc-adpasssync. Grant it read on the domain, create-child and write on the container that will hold the ADPassSync configuration object, and Reset password plus Write lockoutTime on the OUs the portals will serve. Don’t make it a Domain Admin.
  • Decide the DNS names users and servers will use, for example relay01.contoso.com, svc01.dmz.contoso.com and reset.contoso.com.
  • Plan a reboot window for each Domain Controller.

About the certificate warning at 4:11. The walkthrough uses the development mTLS certificates that setup can generate, so the browser doesn’t trust the admin console’s certificate. As setup says, those are for development and testing only: in production, issue certificates from your organization’s PKI or AD Certificate Services.
